## 🌌 About The Project

**AK** is an interactive, cyberpunk-inspired web experience blending glassmorphic UI design, runic digital rain shaders, and live dual-timezone schedule coordination. 

Engineered to solve the friction of tracking daily routines across different geographical regions, **AK** provides synchronized real-time clocks and unified schedules bridging **IST (India Standard Time, UTC+5:30)** and **WIB (Western Indonesia Time, UTC+7:00)**. It wraps functional scheduling tools inside a visually captivating, high-performance canvas experience with reactive particle physics.

---

## ✨ Features

- **🌐 Dual-Timezone Precision Clock**: Real-time synchronized digital glass clocks rendering simultaneous hours, minutes, seconds, and dates for both IST and WIB.
- **🌧️ Matrix & Runic Digital Rain**: Procedural canvas stream simulating glowing Norse runes and binary glyphs drifting through a deep dark backdrop.
- **🎮 Interactive 3D Particle Canvas**: Powered by **Three.js** and **GSAP** for responsive cursor-reactive particle fields and silky ambient motion.
- **📅 Cross-Border Schedule Dashboard**: Comprehensive timeline mapping routines, academic milestones, and collaborative windows across international time zones.
- **💎 Ultra-Glassmorphism UI**: High-end backdrop blur filters, iridescent gradient typography (Orbitron, Space Grotesk, JetBrains Mono), and tactile hover dynamics.
- **⚡ Zero Build Step**: 100% pure vanilla web standards; instant load times, no heavy bundlers required.

## 🛠️ Tech Stack

## 🚀 Quick Start

### Running Locally

Since **AK** is a static client application, you can run it immediately with any local HTTP server:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kecrwn/AK.git
   cd AK
   ```

2. **Serve with Python:**
   ```bash
   python3 -m http.server 8000
   ```
   *or with Node.js `npx serve`:*
   ```bash
   npx serve .
   ```

3. **Open in your browser:**
   ```
   http://localhost:8000
   ```
